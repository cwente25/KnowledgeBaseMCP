# New Employee Onboarding Checklist

## Before First Day

- [ ] Send welcome email with start date and time
- [ ] Prepare workstation and equipment
- [ ] Create accounts (email, Slack, GitHub, etc.)
- [ ] Add to relevant mailing lists and channels
- [ ] Assign onboarding buddy

## First Day

- [ ] Office tour
- [ ] IT setup and system access
- [ ] HR paperwork
- [ ] Team introductions
- [ ] Lunch with team
- [ ] Overview of first week schedule

## First Week

- [ ] Review company handbook
- [ ] Security and compliance training
- [ ] Project overview and codebase walkthrough
- [ ] Set up development environment
- [ ] First one-on-one with manager
- [ ] Assign first starter task

## First Month

- [ ] Weekly check-ins with manager
- [ ] Meet with cross-functional teams
- [ ] Complete required training modules
- [ ] First meaningful project contribution
- [ ] 30-day feedback session

## Notes

This checklist should be customized for each role and department.
